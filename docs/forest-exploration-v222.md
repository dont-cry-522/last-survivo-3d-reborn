# v222 · 森林地势与树群实装记录

开发基线是本地 v221，而不是 Git HEAD 或 v218。修改前的完整快照和哈希清单保存在工作区 `outputs/reborn-forest-v222/baseline/` 与 `baseline-files.json`。本轮仅修改 REBORN，保留此前未提交改动；未提交、推送或修改 NEXT / 原版。

## 地形与路线

- 把沿路的两个椭圆丘改为三种不同横断面：入口的斜脊、沿溪弯折的高岸、溪源附近较宽的台地。它们使用路线方向和受保护空间选择位置，不是均匀叠加随机噪声。
- 现有岩壁背后增加连续远岸脊。它的半长至少 44m、背坡宽 38m，设计峰值 8.4m；溪源台地设计高 6.4m。实际地面仍经过原有水域、奖励、建筑与道路保护及坡度限制，设计高度不等于每个种子的实际高度。
- 既有岩壁下部最多嵌入地面 1.15m，背坡与岩壁连接，不再留出一圈强制平地。岩壁自身从对称圆丘形改为一侧短肩、一侧长肩的连续岩台，保持原来的实体足迹和高度边界。
- 入口、溪流弯道、岩壁、开阔潭岸及溪源沿用既有连续路线。道路、奖励、水体 XZ 坐标、地图边界、移动速度及碰撞规则不变。潭岸保留低而开阔的前沿，较高地势放在两侧和后方。
- 仍使用同一张 144×144 地面网格，41,472 个三角形；角色、相机、投射物、植物和树根共用实际渲染三角形的高度采样。单轴坡度上限仍为 0.22，合成坡度约 0.311。

## 树木结构与分布

原有四族程序枝干及三类基础树保留，本轮实际下载并接入两种外部结构，而非仅把旧树缩放变色：

- Quaternius `CommonTree_1`：多枝的成熟冠层，主要在入口附近形成小群。
- Quaternius `TwistedTree_5`：弯曲、不对称伸展的树冠，分布于溪流转折与潭岸。

资产来自免费 Standard 版 Stylized Nature MegaKit，许可为 CC0 1.0。来源、改造步骤和文件校验值见 [资源清单](../assets/environment/forest-trees-v222/sources.json) 与 [第三方许可](../THIRD_PARTY_ASSETS.md)。

保留源枝干、叶片布局、UV、透明轮廓和法线；上部枝叶一起拓宽 20%，树干下部约束在既有碰撞范围内。根据第一轮实际截图，将源包过艳的黄绿/红叶改为灰橄榄色，红褐树皮改为灰褐色，保留纹理明暗。未增加树位或将树木统一换成同一种新模型。

沿路以确定性的局部树群选择结构，混合保留旧树；相同地图种子可复现。每棵仍为枝干和树冠两个网格，三档树冠 LOD 共享枝干及材质，复用原有游戏时钟风与透光。远景仍是原来的 240 个位置、6 个实例化批次，没有翻倍铺树。

## 加载、资源与性能边界

两份 GLB 共 1,408,152 字节（1.34 MiB），嵌入的贴图最大 512×512，无额外解码器或 CDN。只把两份 GLB、来源清单和两份许可文件放进离线包；104,088,529 字节的下载源包保留在仓库外。

加载器只缓存两套共享模板，失败保留原树，并释放本次失败产生的几何、材质和纹理。正式入口等待加载完成；进入前预热全部树冠 LOD 与路线枝干，避免转头时才上传新枝干缓冲。地形按行、树根、植物批次及贴片分段构建，复用 v221 的加载调度；实际游玩期没有新增地形生成循环。

保留 v221 的桌面 60 / 移动档 30 次渲染目标及原画质选项。渲染提交频率不是屏幕实际呈现 FPS，CPU 提交耗时也不是 GPU 帧时间；手机尺寸模拟不等于 Android / iOS 真机性能。

## 已知限制与后续方向

本轮仍基于现有地图、水位、保护区域和低成本地形网格。部分种子的地势会因奖励或道路保护减弱，不保证每个随机森林都拥有相同的远岸高峰。环境仍是混合程序化与风格化资产，并非完整手工雕刻的商业大型场景。

普通树枝仍沿用既有碰撞处理：树干是实体，较高枝条不会因为本次美术升级新增整冠碰撞。没有改战斗、敌人数、奖励、角色数值或其他地图的视觉方向。下一步应根据实际眼平视角继续改善坡面与树林疏密的衔接，而不是继续叠加泛光和雾。
