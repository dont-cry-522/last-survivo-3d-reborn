# v214 · 树木、地形与建筑环境打磨

本轮基于本地 v213 继续修改《异境回响》NEXT，保留原版与已有玩法。本记录描述实际代码变化；目前为**本地开发版，尚未提交、推送或发布到 GitHub**。最终浏览器检查、离线包和全量测试结果在文末单独登记，未完成的检查不计为通过。

## 从局部物件转向完整环境

### 树木轮廓

森林树木继续使用原位置和根部碰撞范围，调整完整树冠的立体比例、枝组分布与中心连接，减少水平叶片像托盘、树干撑着统一伞盖的感觉。雪地针叶树采用错落下垂的枝层与圆脊雪簇，仍保留枝下的暗针叶和树梢。没有通过增加树木数量来填满视野。

沿用共享几何体、共享叶材质和原风动时钟，暂停不会继续推动树叶。每棵树仍由树干和树冠两个网格组成，保留三档 LOD。树冠面数如下；它们是单棵树的几何量，**不是帧率测量**：

| 树冠 | 近档：v213 → v214 | 中档：v213 → v214 | 远档：v213 → v214 |
| --- | --- | --- | --- |
| 森林 | 9,000 → 5,400 | 3,600 → 2,400 | 600 → 600 |
| 雪地 | 5,256 → 3,960 | 1,368 → 1,368 | 396 → 558 |

雪树远档保留圆脊需要多 162 个三角形，近档有所减少；不能据此声称雪地任何机位都会更快。保留最初的中档预算，并将开发中一度达到 1,044 面的远档降到 558 面。雪岩景观簇中的小型针叶树另用紧凑冠，维持原 396 面；其 14 个景观簇合计 24,052 面，不把普通大树的额外细节重复塞进岩石合批。

### 能行走的宽缓地形

在原有地面高度网格上形成宽缓的林坡、雪丘、灰烬肩坡、沙丘和海岸土坡。每张独立地图最多选取八处候选地势，五境中每个区域最多四处；不是额外堆放不可穿越的山石。地表颜色随坡顶轻微变化，现有草、石与道路表层贴合相同高度。

沿用真实三角形的高度插值，人物、敌人、跳跃与弹道使用同一采样。现有障碍物根部、水岸、桥梁、地点及主要路径保留平面保护；不新增碰撞障碍。高度上限 1.2 米，横纵网格坡度上限 0.12。独立地图仍为 144×144 网格，五境为 160×160；道路和地面覆盖层的贴合细分仅在建图时进行，上限为额外 8,192 个三角形，不增加绘制批次。

以下是固定种子 522、按实际建立地图顺序运行后，网格顶点高度大于 0.001 米的占比。它反映起伏覆盖的变化，不等同于精确面积占比，也不表示所有站位都能看见全部地形。

| 地图 | v213 | v214 | 本次实际最高地势 |
| --- | --- | --- | --- |
| 森林 | 2.65% | 27.03% | 1.148 米 |
| 雪地 | 3.72% | 29.08% | 1.099 米 |
| 灰烬 | 3.52% | 25.36% | 1.049 米 |
| 沙漠 | 9.81% | 28.46% | 1.197 米 |
| 海港 | 2.45% | 20.60% | 0.881 米 |

这次测量中，地形生成阶段单图增加约 16–29 毫秒，五境增加约 97 毫秒。它是单次 Node 构建记录，不是多轮性能基准；不能换算成浏览器 FPS。高度查询仍使用原固定网格插值，没有新增逐帧全场地形搜索。

### 远景山体

把连续环绕的山脊组织成三至四组不等宽、不等高的山体，前后层独立错位，在山群之间留下宽低谷。森林强调宽缓林坡，雪地强调峰群与雪槽，灰烬强调断裂火山群，沙漠强调平顶台地，海港强调分离岛岬。

继续使用原两层网格：**6,144 个三角形、一个材质、一个绘制调用**。不新增山体贴图、灯光或后处理；保持既有太阳、月亮、雾与曝光参数。海港整层近岸支撑面的位置和颜色保留，已有建筑承托、船只水道及湾口开口继续有效。五境边界使用原生物群系权重过渡。

### 建筑与遗迹

本轮重点重做海港仓棚、残船及沙漠废墟的结构。仓棚采用中央高、外檐低的连续人字坡，带搭接木板、屋脊和三角支架；货箱有分板与框条。残船由平板和两排木条改为弯曲船壳与肋骨。沙漠矮墙分为有接缝、磨损边缘的石砌层；码头木构与灯塔细节沿用原位置打磨。森林、雪地、灰烬的既有遗迹没有在本轮全部重建。

静态部件在每个原碰撞根节点内按表面合并，保留易碎墙各自的销毁流程；高处屋面与支架单独保留实际射线外形。仓棚最低支架高于 3 米，入口、柱脚和地面通行碰撞不变。屋顶调整已经过上下方向射线和连续性检查，不能把未合并的屋顶简单作为无碰撞装饰。

同一组建筑样例、固定种子 522 的结构统计：海港四类样例由 **81 → 44 网格、18,244 → 21,424 三角形**；沙漠样例由 **61 → 41 网格、17,464 → 17,344 三角形**。这是样例网格成本，不是整图绘制调用或 FPS；海港新增真实屋顶和船壳细节增加了部分三角形。海港仓库与残船的实际画面单独列在本轮对照页中。

## 主要文件

- `tree-scenery.js`、`forest-habitats.js`、`environment-clusters.js`：完整树冠、枝组连接、LOD、景观簇幼松预算与原动画兼容。
- `forest-terrain.js`：有限宽缓地势、保护范围、表层贴合与原高度采样。
- `environment-lighting.js`：已有远山网格的大轮廓；没有更改环境灯光参数。
- `district-models.js`、`map-districts.js`：木屋面、屋架、曲面残船、石砌墙及原碰撞节点内合批。
- `tests/district-models.test.js`、`tests/adventure-overheads.test.js`：建筑外形包络、屋顶与支架射线、通行和资源回收。
- `tests/forest-terrain.test.js`：原地形射线测试改为确定性的空间与高度分层抽样；每个种子验证两个三角形内点，至少 100 个真实射线命中。所有保护区和网格坡度遍历仍保留，命中精度仍为 `1e-6`。

其余涉及 `?v=214` 的文件变化需与实质代码变化区分。没有把全部版本号更新当作玩法或模型改造。

## 体验与限制

本地服务启动后打开 `/play.html?v=214`，选择五张独立地图或五境大远征。建议先看大厅地图背景，再进入第一人称观察树冠、开阔处起伏和远处山谷，最后切回第三人称确认道路与人物落地关系。

最终 ZIP 已输出为工作区 `outputs/异境回响-v214-离线完整包.zip`，逐项哈希与 CRC 验证通过。解压后使用 `START_OFFLINE.cmd`，不要以 `file://` 直接打开模块页面。原 v213 包保留。

实际浏览器同机位计数见 `render-comparison.json`：40 个样例三角形变化约 −0.9% 至 +2.2%，绘制调用变化 −28 至 +6；最大 970 次。森林独立图三角形略降，雪地独立图增加约 1.7%–2.2%，海港此入口不变。电脑基线为本轮开始时采集的 v213，手机基线为上一轮保存的最终 v213 报告，种子、机位与尺寸相同。这些是实际提交给渲染器的计数，不能据此承诺设备 FPS 或完全无卡顿。没有新增全屏后处理，也没有通过减少怪物或玩法内容换取这些数字。

本轮仍是原游戏程序化环境的形体和布局打磨，不是所有树木或建筑都换成扫描资产。没有实测 Android / iOS 真机 FPS，未确认各桌面浏览器的持续帧率，也不保证所有设备完全无卡顿。主体玩法、攻击、技能数值、角色数量、存档隔离和手机操作规则保持；整体自然度与是否更有探索欲仍需实际试玩判断。
