升级选项从该角色可用的池中随机抽取，并减少相邻轮次重复出现；武器路线从角色等级 3、5、8 起具备相应进阶资格，不保证升到某级就固定出现某张卡。路线选定后，本局不能改选另一条。

当前每级经验需求为 `48 + 7 ×（当前等级 − 1）`。升级次数先暂存，自动选卡避开近身危险、围猎与首领战，选完或延后后至少等待 18 秒才再次自动出现；可点「选择成长」主动打开，「稍后选择」保留原卡片。详见[技能与搭配](03-技能与搭配.md)。

首轮围猎约在 31 秒到来，提前 5 秒预告；独立地图在 120 秒起尝试生成第一位首领；击败后间隔 75 秒继续迎战下一位，击败本地三位后通关。5 张地图合计 15 位不同首领。五境仍需完成各区地标并领取奖励、靠近路标唤醒守卫，击败五位通关。准备页显示所选地图的首领与目标。新介绍只在战斗空档展示 4 秒，消退后至少留出 20 秒；已经展示的介绍保存在当前浏览器，跨局不重复弹出，完整内容可从「?」查阅。

## 现有角色的玩法对照

下表的定位和思考问题是对现有机制的设计归纳，不是额外被动或隐藏加成。

| 角色 | 已有核心行为 | 构思新角色时要比较的区别 |
| --- | --- | --- |
| 林地游侠 | 持枪或火杖输出，翻滚调整位置，陷阱和反击配合 | 新角色是否也只是远程射击加普通翻滚？ |
| 霜影 | 短弩集中攻击、飞镖散射或暗法球，瞬移调整站位 | 新角色的集中攻击和闪避用途是否有不同的决策？ |
| 影裔 | 牵影咒刻印、近战战镰、延迟裂口，暗影控制与追击 | 暗色外观之外，攻击轨迹和触发节奏是否也不同？ |
| 潮行者 | 长叉三连回钩或持续引雷，潜潮期间移动避险后浮出 | 新近战是否能在接近、出手、撤离三个环节形成区别？ |
| 铃芽 | 石弹标记或抛物线荆果，与獾兽协作，方向燕步或伙伴换位 | 新召唤角色是否有不同的伙伴指令、目标选择和生存代价？ |
| 雾苓 | 抛毒囊布区或长鞭抽打留毒，沿实际闪避路径搬运；毒灯守区与长鞭距离管理各有取舍 | 新区域角色是否改变空间决策，而非叠加更多同类持续伤害？ |
| 雾苓·蜃影 | 毒团牵制或展开、合拢的扇风，蜕影留下有限生命的诱敌替身；扇风回流围绕原出手位置 | 是否需要保护诱饵到期，还是牺牲它换取脱险？别把替身视为另一只攻击宠物 |

## 怎样用这套资料构思新角色

1. 先用一句话写出“玩家需要反复做什么选择”，例如选择出手时机、回收武器的位置或伙伴的攻击目标。
2. 从角色对照表找出最接近的现有角色，写清楚新角色与它的实际操作区别。
3. 查武器资料，选一个相近的伤害、距离和攻击节奏作为试作参照；不要把单次伤害直接当作整套技能伤害或每秒伤害。
4. 再设计两条成长路线，让它们改变攻击节奏、覆盖方式或目标选择，并写出各自的取舍。
5. 用技能资料检查触发条件、数量上限、冷却、首领例外与恢复能力，避免无限连锁或无限控制。
6. 最后填写动作、特效、声音和手机操作要求，再决定制作顺序。

以上是设计建议，不表示游戏已经实现这些新方案。模板中的空白也不代表待办承诺。

## 数值阅读约定

- 基础武器数据不包含通用强化、遗物、围猎奖励、技能追加伤害或特殊命中加成。
- 武器范围使用游戏中的世界距离；远程攻击还会受到可见战场、遮挡和实际落点的限制。
- “每秒攻击次数”是配置频率。弹弓无需等待弹体返回，命中率仍受瞄准、走位和遮挡影响，不能只乘伤害算作稳定输出。
- 武器路线、技能、遗物是不同系统；同名的“藤绊”或相近的“复诵”也可能有不同触发条件。
- 技能文案与结算存在差异时，资料会单独说明。比较新角色时，以实际实现为准。
