# REBORN 本地新增地图与探索

[返回目录](README.md)

当前本地代码提供七张独立地图：翡翠幽林、霜月峡谷、赤烬荒原、风蚀遗城、幽潮遗港、雾钟山谷、星辉晶窟。五境大远征保持原来的五区连接；本轮没有把新图塞进合流地图，也没有修改旧图的通行、奖励或战斗数值。

两张新增地图从 v228 起提供；旧 v227 发布包不包含它们。版本、画面与验证记录以对应发布包为准。

## 雾钟山谷 `bellvale`

以青灰山地、低饱和草坡和旧铜风钟区分森林。两条不对称岩脊之间留下连续曲折谷道；真实缓坡最高约 6.5 米，角色、怪物、相机落脚高度取自可见地形的同一组三角面。稀疏高冠树和草地保留谷底视野。

| 路线位置 | 实际景观与通行 |
| --- | --- |
| 南侧山口 `(-45,55)` | 安全出生点，沿浅色谷道看到第一个钟门 |
| 山口风钟 `(-19,31)` | 两柱之间的拱门和悬挂铜钟；基本门洞宽 7.8 米，立柱为实体 |
| 折溪古门 `(-37,-15)` | 岩脊与古门形成转弯；溪流在谷道另一侧，能够从干地绕行 |
| 回声钟庭 `(29,-57)` | 较大的铜钟与开阔坡肩；北侧门洞有三扇实体木栅，主路线绕其南侧折向东侧 |

- 五处事件点：遗物、古门机关祭坛、两处补给（其中一处伏击）、远处祭坛。
- 清理钟庭机关守卫后，选择「开启捷径」会移除钟门下三扇木栅并恢复 25% 生命；选择「挑战宝库」则保留门、迎战第二批守卫领取技能。木栅不挡住原主路线，房主开启后客户端同步消除碰撞。
- 两片现有水面材质的溪潭，涉水与游泳沿用原规则。
- 五处「遗落铜铃」：安全接近后领取 15 经验与 8% 生命恢复，每处一次，约 10 / 45 / 80 / 115 / 150 秒开始可发现。
- 三套围猎：钟门护送、风谷双哨、回声狼袭。编队均六名、一名精锐，保留侧面撤退空间。
- 普通生态复用蘑菇、狼、盾卫、冰巫与萨满；空中复用霜羽蛾。
- 首领依次为荆冠鹿王、断碑守卫、裂冰晶凰。

地面复用森林本地扫描土壤与凹凸纹理，岩脊、石门复用现有 CC0 岩面纹理，按真实空间尺寸取样。草丛采用原森林的弯曲尖叶和根部渐变，共享暂停感知的微风，而非竖直矩形纸片。新局视线沿首段谷道，不再朝向出生点背后的边界。

光照使用暖日光与青灰天光，复用现有三灯和本地环境反射；没有为每个钟门增加灯光。原有音频合成器播放 94 BPM、6 拍的原创巡行旋律，风笛、木质音与低音分层，危机时加入原有打击节奏。铜钟有小幅异相摆动，目前没有新增现场采样的钟声资源。

## 星辉晶窟 `crystalcave`

以冷青蓝矿石、暗蓝灰洞壁和偏紫晶群区分地表地图。三座高拱洞厅按弯曲路线相连，外围有连续起伏洞壳和边界岩壁；内部洞厅之间保留侧面和端部通路，不再从拱顶缺口看见大片室外蓝天。

| 区域 | 实际景观与通行 |
| --- | --- |
| 洞口 `(-55,45)` | 干燥出生区，进入月隙前厅 |
| 月隙前厅 `(-37,22)` | 较低的第一座高拱，转向地下潭边的宽廊 |
| 星辉主厅 `(29,-8)` | 最高洞顶和较宽开口；晶簇与洞壁分隔不同绕行方向 |
| 回晶深廊 `(-10,-59)` | 第三座较长洞厅与显眼晶群，通往北侧祭坛 |

- 地面设计为低缓岩肩，最高约 2.4 米；三座局部拱顶中心约 18–24 米，外围连续洞顶约 13–25 米。顶壁参与现有屋顶、投射和第三人称相机查询。
- 连续洞壳命名为 `SM_Cavern_ContinuousShell`，墙体位于可玩边界之外，不会堵路。地面、岩柱、洞壳共享按米取样的本地岩面颜色与凹凸纹理；新局面朝第一段晶廊。
- 独立岩壁、晶簇是实体，连续主路与所有事件点保留可通行缺口。
- 五处事件点：遗物、晶灯祭坛、两处补给（其中一处伏击）、远处祭坛。
- 两片地下潭；水面、涉水、游泳沿用原流程。
- 五处「星辉晶簇」：安全接近后领取 20 经验与 4% 生命恢复，每处一次，出现时间与原独立地图一致。
- 三套围猎：晶壳推进、幽潭双灯、回晶钩爪。
- 普通生态复用霜兔、甲虫、岩甲、水母与浮霜晶核；空中复用暮翼蝠。
- 首领依次为噬梦蛛后、深渊灯母、断碑守卫。

光照使用冷色环境补光、低强度主光与紫灰反射；晶体采用低强度自发光材质，没有增加成片动态点光源。关闭室外天空球并使用深蓝灰空气透视，不生成森林远山或远景树柱。连续洞壳不把整张地图盖成全黑阴影，局部岩柱继续投射阴影。背景音乐是原音频体系内的原创 84 BPM、8 拍回响主题，木质音、拨弦与持续音留出停顿；不是外部商业游戏配乐。

## 共同规则、资源与验证边界

- 每张独立地图范围约 192 × 192 米，地面使用 128 × 128 网格；每次重开可改变细小布局，但相同种子可复现同一地形、树石、奖励与遭遇。
- 两图都沿用 120 秒起第一位首领、前两轮击杀后间隔 75 秒、击败第三位结束。首领模型总量仍为原 15 种。
- 复用现有岩石、树冠、植被纹理、水面、环境反射、怪物与动画；新地形、钟门、铜钟、拱顶和晶簇由项目内几何代码构建，没有下载新资产或增加运行时 CDN。
- 草丛与碎晶使用有上限的实例批次，分别最多 560 / 180 个；草丛仍为一个实例绘制批次。种子 42 的建图静态三角数约为山谷 14.55 万、晶窟 5.45 万，不等同于整帧渲染三角数或 FPS。谷地树木与洞壁保留独立碰撞；没有通过减少旧图敌人、降低伤害或关闭机制换取性能。
- 所有运行时文件进入现有离线清单。实际发布须重新运行 `npm run offline:build`、`npm run offline:check` 和测试；这份说明不等于已发布新 APK 或 ZIP。

`tests/new-expedition-maps.test.js` 覆盖三种种子的可复现布局、路线与奖励可达、实际三角高度、洞顶查询、奖励一次性领取、联机发现物同步、完整场景安装链、一/三人称相机、跳跃落地及几何释放；另用曾暴露问题的种子检查发现物不会被随机树石挡住。

站点复用旧地图的真实路迹网格，并贴合实际地面，发现时与站点一起显示。`tests/new-map-site-lifecycle.test.js` 直接执行游戏内 `updateSite` / `updateSiteEvent`，覆盖两图全部十个站点的首次发现、守卫、晶灯充能、机关开门、奖励只领取一次和客户端路迹同步；不是仅检查造型能生成。

本轮地图相关自动化检查包括原五图与合流的分步构建回归，以及钟庭真实开门和联机移除碰撞检查；最终执行数量与结果见交付报告。代码检查无法判断画面吸引力、音乐听感、完整局平衡或真机帧率；游戏内截图、桌面与手机尺寸运行结果由本轮交付报告单独列出，不能把这些单元测试算作实机画质或性能验证。
