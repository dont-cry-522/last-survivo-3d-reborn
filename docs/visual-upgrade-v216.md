本轮在已有未提交的 v213–v215 基础上继续，未回滚旧工作、提交、推送或发布。Three.js 实际版本为 r180，继续使用 WebGLRenderer；原七英雄、17 武器、地图、存档、首领与战斗数值保持。

## 光照与渲染

- 明确输出 SRGB；颜色贴图保持 SRGB，法线/粗糙度/金属度和 HDR 保持线性。实际比较 ACES 与 AgX 后保留 ACES，当前低饱和林地与白发在 AgX 下更灰。离屏 HDR 只在最终输出做一次色调映射。
- 加入本地 Poly Haven 1K HDR，经线性亮度归一化与高亮压缩后生成 PMREM。保留原场景天空，避免第二个刺眼的 HDR 太阳。森林使用林下环境，其余地图使用开放天空；五图原有各自的太阳、半球光、雾色与曝光继续工作。
- 反射强度：森林 0.30、雪地 0.36、灰烬 0.17、沙漠 0.29、海港 0.38；森林深夜降至白天的 22%。五境过渡淡出切换，地图建设/首次预热直接绑定最终环境，避免解锁游戏后再编译一遍材质。
- 桌面 PMREM 每份 768×1024，手机每份 384×512；手机 GPU 反射像素量为桌面的四分之一。源 HDR 和临时预滤资源在完成后释放，两个成品跨地图复用，退出页面释放。
- 大厅保留地图太阳作为主光，增加一盏局部轮廓光，与已有柔和补光组成角色照明。两盏局部灯都不投影，仅在预览绘制时加入并随即移除，不带入战斗场景。
- 皮肤旧法线幅度由 0.65 降至 0.14，保留新曲面主导鼻、眼睑与颊部；粗糙度 0.72、金属度 0。武器铜、钢、刃口和布料保持各自材质。
- 太阳阴影 bias 从 -0.001 改为 -0.00025，normalBias 从 0.025 改为 0.018；沿用脚部接触阴影与主要物体投影，不给小草添加新投影光。
- 泛光提取区间由 0.70–1.25 提高至 1.05–1.85；移除后期额外 9% 对比曲线，避免只有后期开启时黑衣细节被压掉。原水下表现保留。不新增 SSAO、SSR、景深或多套全屏处理。

## 画质档位

现有“声音 / 画面”设置内加入自动、高画质、均衡、移动；电脑暂停内有画面设置，手机仍集中在暂停 → 设置。设置独立保存，私密模式存储失败不影响游戏。

| 档位 | 桌面像素预算 / DPR 上限 | 手机像素预算 / DPR 上限 | 阴影 |
| --- | --- | --- | --- |
| 自动 | 320 万 / 1.5 | 180 万 / 1.35 | 桌面1536，手机1024 |
| 高画质 | 415 万 / 1.75 | 220 万 / 1.5 | 桌面2048，手机1024 |
| 均衡 | 240 万 / 1.25 | 150 万 / 1.15 | 1024 |
| 移动 | 110 万 / 1.0 | 110 万 / 1.0 | 768 |

所有档位均保留自适应清晰度；均衡/移动优先取消额外 HDR MSAA，仍保留原后期。长时间负载高时沿用现有直接渲染回退。只改变绘制预算，不减少敌人、修改伤害或关闭玩法。画布尺寸改为一次 setDrawingBufferSize，避免重复分配。
