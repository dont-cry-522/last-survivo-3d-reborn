# v215 · 七位英雄的本地网格重建

本轮优先改善可玩英雄，保留七位身份、17 种武器、既有技能和战斗数值。角色仍使用原来的 65 骨骨架与动画，修改的是可见网格和局部材质，不是替换整套玩法、动作系统或摄像机。

## 新资源、工具与离线方式

本轮**新下载且实际采用**的外部模型只有 Quaternius Universal Base Characters 免费 Standard 中的 `Hair_Buzzed` 和 `Hair_Beard`，合并为游侠头发网格。来源：[作者官方具体资源页](https://quaternius.com/packs/universalbasecharacters.html)，许可 [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)。原始许可保留在 `assets/characters/universal-base-characters-LICENSE.txt`。

其余角色保留现有 Quaternius CC0 人体、服饰和骨架基础，在 Blender 中重塑或重建可见表面。新下载的 `Male_Peasant`、`Hair_BuzzedFemale` 未采用；重取的 `Female_Peasant`、`Hair_Buns`、`Hair_Long` 是原有资源的校验副本，不计作新角色素材。

本机 Blender 4.5.9 LTS 的签名已核对为 Blender Foundation；真实后台制作采用焊接、曲面修形、细分、平滑、窄边厚度和限量减面。Blender MCP 本地初始化、场景读取和执行建模后导出 GLB 均做过验证；生产文件使用 Blender 后台脚本生成，没有调用付费 AI 生成接口。未从商业参考游戏提取模型。

当前清单为 **12 个 GLB，共 5,769,436 字节（约 5.50 MiB）**，全部在 `assets/characters/rebuilt-v215/`。哈希文件由 `hero-refinement-assets.js` 引用，逐文件来源、字节数与 SHA-256 见 [`assets/characters/rebuilt-v215/sources.json`](../assets/characters/rebuilt-v215/sources.json)。不新增运行纹理；服装复用既有本地贴图和材质，游侠短发/胡茬采用顶点颜色。未把源下载包、Blender 工具或未采用模型加入离线包。

`hero-refinements.js` 按 `targetName` 替换表面，按骨名复用当前骨架与权重，保留原命名 morph、独立材质回调和原动画。新增 GLB 加载或属性校验失败时，保留对应的旧部件。继续共享可复用表面，表情值与需独立释放的面具部件保持实例独立，不引入逐帧建模。

## 制作与集成文件

- `scripts/export-hero-rest.mjs`：导出游戏实际休止态，而不是猜测源模型比例。
- `scripts/hero-blender-tools.py`：创建 Blender 网格、执行修改器、采样归一化权重、保存 UV/颜色和 morph；规范化整数颜色，避免把 255 当作浮点颜色造成纯白。
- `scripts/prepare-ranger-tide-attire.py`、`prepare-mist-heroes.py`、`prepare-lingya-attire.py`、`prepare-lingya-head-v215.py`、`prepare-scout-hair.py`：各角色的可复现制作过程。
- `scripts/pack-hero-refinements.mjs`、`hero-refinement-assets.js`、`hero-refinements.js`：本地资产打包、缓存标识与兼容回退。
- `assets/characters/rebuilt-v215/`：正式运行模型、来源和许可。
- `skinned-hero.js`：在现有模型装配流程中接入替换、保留表情与面具缓存。
- `scripts/build-offline.mjs`：将选定的哈希模型与来源文件加入离线资源清单。
- `creature-anatomy.js`：以下三类雪地生物的肢体曲面修正；相应验证在 `tests/creature-anatomy.test.js`。
