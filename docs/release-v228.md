# REBORN v228：岚歌与回声之旅

本版在原 v227 基础上加入岚歌、两件武器、两张地图，以及此前保留在本地的好友房间功能。开发、发布和安装包均属于 REBORN；NEXT 与更早的原版保持独立。

## 可玩内容

- **岚歌｜巡风乐师**：风弦长弓、回音战铃、踏风步，以及踏风引弦、三叠和弦、静音衣。长弓经历拉弦后释放，战铃声波向前推进，抵达外缘后从原释放位置发出一次延迟回声。两件武器各有两条互斥路线。
- **雾钟山谷**：缓坡、岩脊、溪潭与钟门形成连续路线，钟庭机关可以实际打开木栅捷径。
- **星辉晶窟**：三座相连洞厅、连续洞顶与边界岩壁、地下潭和晶群；地面与顶壁参与原有通行、相机和弹道查询。
- 两图各有探索奖励、漫游事件、围猎与三轮首领。怪物和首领使用既有模型的不同组合，并非新增六个首领模型。原五图与五境合流的核心规则保持。
- **好友对战**：最多四人，玩家互相对战，场上也有怪物。由房主运行世界模拟；完整邀请链接支持手机或电脑浏览器。具体玩法和连接边界见[私人房间说明](PRIVATE_ROOMS.md)。

武器数值、技能触发与地图路线分别见[武器参考](设计参考/02-武器与升级路线.md)、[技能参考](设计参考/03-技能与搭配.md)、[地图参考](设计参考/07-新地图与探索.md)。

## 岚歌外观与动作

在兼容的女性骨架上制作自己的衣服与发型。针对初版肩袖拼接、腰裙穿插和管状发束的问题，衣服改为连续廓形，袖子沿真实肩肘拓扑贴合，外衣增加厚度并统一内外层蒙皮；发型改为连续后脑体积、斜分刘海与低马尾。头部只在本角色副本上柔化眉颌与面部明暗，保留眼部绑定。

拉弓与摇铃保留各自出手、回收及第一人称持握。修复踏风步表现中滚转角逐帧累积的问题，没有改变位移、碰撞、冷却或无敌数值。不是只更换颜色，也没有替换不兼容骨架；面部仍以现有基础模型为起点，近景精度尚不能等同于专门制作的高精角色资产。

本次没有下载新模型或使用收费生成服务。新衣服、发型和武器使用本地网格代码及已有授权资源，地图复用本地纹理、植被与环境反射。运行时不新增外部 CDN。

## 更新与存档

Android 使用原包名 `io.github.dontcry522.realmechoes.reborn`、原签名证书与 `https://appassets.androidplatform.net/game/` 来源。新安装版为 `228.1`，版本码 `22801`。已有同包名版本可覆盖安装；不要先卸载或清除数据。

Windows 包同时包含两个入口，游戏资源只保存一份：

1. `启动异境回响.exe`：原全屏离线单机，继续使用 `http://127.0.0.1:8897` 与原 Edge/Chrome 用户资料。更新后选择之前游玩的同一浏览器。
2. `START_ONLINE_ROOM.cmd`：联网开房，使用独立的 8898 服务和包内运行时。朋友从完整邀请链接加入；房主服务与页面需保持打开。

Android APK 保持离线单机。手机好友对战仍从系统浏览器打开房主邀请，不宣称 APK 内已实现公网开房或加入。

原设置、图鉴与远征记录键未变。新增内容只扩充合法通关组合，保留旧记录，包括已退役武器的历史记录。不清理原版、NEXT 或其他浏览器的数据；不同站点、浏览器、APK与临时公网网址的存档不会自动互通。游戏没有新增“保存正在进行的战斗”功能，更新不能恢复未结束的对局。
