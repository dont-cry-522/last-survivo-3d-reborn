# REBORN v229：岚歌面容与动作精修

本轮只针对岚歌的面部、头发和持械协调继续制作。沿用原骨架与武器挂点，不改变伤害、攻速、移动、闪避、碰撞、成长路线、地图或房间规则。

## 实际修改

- 在岚歌独立的蒙皮网格副本上调整眉骨、下颌、鼻翼与唇颊过渡，维持原拓扑索引、骨骼与权重。单层眉毛采样实际皮表，替换原来折叠、重叠的眉片。
- 面部不再依靠基础贴图中刻画过重的眼窝、鼻颊阴影；保留轻微肤色差异，让实际场景光线塑造明暗。未调整公共灯光和曝光来掩盖面部问题。
- 发际线与侧分流向并入连续发冠，耳侧发型由同一曲面收拢，低马尾从后脑聚拢后垂落，消除独立鬓发带与暴露的马尾根部切面。发根固定，发梢轻摆；运动法线与变形同步，避免高光不跟随发束。
- 修正长弓贴胸、拉弦手偏离弦、抬手翻腕的问题。先平滑可达的手部目标，再解算双臂；满弓肘部在肩侧打开。走跑时空手摆动，头部轻微抵消肩部转动。
- 战铃的空闲手回收为放松姿势，第一人称同步拉弦手型、摇铃引导手与取消后的平顺回收。

未下载新模型、纹理或录音，也没有使用收费生成服务。现有资产来源不变。头发仍是本地制作的风格化程序网格，面部仍以兼容的现有角色网格为基础；没有新增眨眼、口型或宣称完成写实发丝资产。

主要代码为 `minstrel-appearance.js`、`skinned-hero.js`、`weapon-grips.js` 和 `first-person-view.js`；新增脸发与动作回归测试。离线版本、安装包版本与角色表现参考同步更新。

## 对比方法

修改前基线来自提交 `068c58fc5f058a57c6e2428466a5940c4de6f335` 的隔离快照，368 个资源的哈希与 `228-cb555a57e176` 清单逐项一致。没有回滚工作仓库来拍摄旧版。

工作区 `outputs/minstrel-refine-v229/` 保存真实浏览器结果：

- `before-unobstructed/` 与 `release-face/`：正面、侧面、四分之三角度和后脑近景。近景为模型检查相机，隐藏武器以免挡脸；不冒充实际战斗取景。
- `motion-before/`、`motion-after/`：同机位、同地图、同动作阶段的实际游戏图，每组 16 张，包含持械、抬弓、满弦、释放、回收、跑动与第一人称。两次页面脚本异常均为零。动作对比中的面容是当时工作版本，最终外观以最终脸发与实景图为准。
- `compare-motion-bow-draw.png`、`compare-motion-running.png`、`compare-motion-bell-release.png` 与 `motion-compare.html`：动作前后对照。
- `compare-face-three-quarter.png`、`compare-face-front.png`、`compare-face-side.png`、`compare-face-back.png`：同一光照与机位的原版/最终版真实截图并排。没有用生成图片代替运行结果。
- `release-scene/`：冻结版大厅、森林第一/第三人称，以及两种武器正侧背面、行走、跑动、攻击和闪避；页面脚本错误为零。

近景脸发是否足够美观、连续射击的主观手感，仍需要玩家在自己的设备上体验；不能用自动检查替代审美和手感判断。

头发由 7 个网格、5,264 个三角形调整为 3 个网格、4,560 个三角形；眉毛由 1,480 个三角形调整为 384 个，两者净减少 1,800 个三角形。持弓英雄可见三角形总数为 41,498，逐帧形变发顶点由 1,694 降为 770。减少的是重复部件与不必要的折叠，不靠降低画质档位、减少敌人或删去玩法维持性能。
