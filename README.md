# 异境回响

一款可切换第一人称与第三人称、自由转动视角的 3D 生存冒险游戏。在森林、雪地、灰烬、沙漠、海港、山谷与晶窟中探索，选择武器与成长路线，迎战各地守卫。

[开始游戏](https://dont-cry-522.github.io/last-survivo-3d-reborn/play.html?v=230) · [安卓与电脑版下载](https://github.com/dont-cry-522/last-survivo-3d-reborn/releases/tag/v230) · [角色与技能资料](docs/设计参考/README.md) · [完整更新记录](docs/更新记录.md)

这是从 [3D NEXT](https://github.com/dont-cry-522/last-survivo-3d-next) 当前本地工作区完整复制的新方向开发仓库，包含当时尚未提交的代码与模型。原仓库和网址继续保留；新副本的存档、设置与离线缓存独立。复制边界及制作中内容见 [复制说明](docs/COPY_SOURCE.md)。

从[原版 v114](https://github.com/dont-cry-522/last-survivo-3d/tree/1dd7466fc82e48a98e266d09df49a5de1fce967f)复制的独立开发版本，保留完整提交历史与游戏资源。后续开发在本仓库进行；[原版网址](https://dont-cry-522.github.io/last-survivo-3d/play.html?v=114)继续保留。两个版本的存档、偏好设置与离线缓存相互独立。

## 当前可玩内容

- 8 位英雄、19 种武器、38 条武器路线。巡风乐师「岚歌」使用风弦长弓或回音战铃，分别体验拉弦射击和延迟回响声波；配有踏风步及三个专属技能。
- 7 张独立地图与连接原五种环境的「五境大远征」。新增雾钟山谷、星辉晶窟，各有探索奖励、围猎和三轮首领。新地图使用现有首领的不同组合，首领模型共 15 种。
- 支持电脑与手机、迷雾探索与完整地形显示；下载完整资源后可离线游玩。
- 最多四人的好友房间：玩家互相对战，场上也有怪物。电脑版附带公网开房工具，朋友使用完整邀请链接从手机或电脑浏览器加入，无需同一 Wi-Fi 或 VPN。详见[开房说明](packaging/rooms/README.md)。

英雄各有衣装与器物特色；铃芽使用芽铃弹弓，与獾兽伙伴配合作战；影裔以窄白衣缘、黑刃白锋和黑封白页呼应幽影身份；岚歌以铜棕发、象牙衬衣与蓝灰旅行服形成轻装乐师轮廓。第一人称同步持械动作，详情见[角色与武器表现参考](docs/设计参考/04-表现与制作参考.md)。

v230 减少镜头避让岩壁、群怪移动和第一人称绘制中的重复计算，保持原有画质、模型、怪物数量与玩法。实际测量及仍存在的性能边界见 [本次记录](docs/performance-v230.md)。

准备页选择人物、武器、地图和攻击模式，查看该地图的首领、招式和通关目标，再点击「踏入荒野」。首轮围猎约在 31 秒到来，独立地图约 2 分钟后迎战首领；五境大远征需完成各区地标并领取奖励，再靠近路标唤醒守卫，击败全部五位通关。首次交互后开启声音；右上角「声音 / 画面」可切换音效版本、调整音量和画质档位，并保存在当前浏览器；手机在暂停 → 设置中操作。

## 操作

| 操作 | 电脑 | 手机 |
| --- | --- | --- |
| 移动 | WASD / 方向键 | 左摇杆 |
| 转动视角 | 第一人称直接移动鼠标；第三人称右键拖动或锁定鼠标 | 拖动画面空白处，或拖动右侧攻击键 |
| 瞄准与攻击 | 画面中心准星，按住左键 | 自动瞄准时按住攻击键；手动时中心准星瞄准 |
| 第一 / 第三人称 | V / 顶部「视角」；第三人称滚轮调整距离 | 暂停 → 设置 → 视角 |
| 闪避 / 角色能力 | Shift | 闪避按钮 |
| 跳跃 | 空格（落地后可再次起跳） | 跳跃按钮 |
| 下蹲 | 按住 Ctrl，松开站起 | 蹲下按钮切换 |
| 暂停与继续 | Esc（释放鼠标）/ 暂停按钮 | 暂停按钮 |
| 探索地图 | M / 点击小地图 | 点击小地图 |

升级次数会暂存到「选择成长」按钮，可主动点开，也可按 Esc 从暂停菜单选择成长；自动选卡等待战斗空档，两轮至少间隔 18 秒。点「稍后选择」保留本轮卡片和次数。新介绍仅短暂显示，已经展示的内容跨局记住；电脑完整图鉴仍可从右上角「?」查看；手机从暂停 →「图鉴与介绍」查看，遇到一种新增一种。

v115 为自由视角首个可玩版本：可在同一局切换第一 / 第三人称，移动与闪避跟随镜头水平朝向，第三人称镜头遇到树石会缩近。普通枪弹与法术弹具备上下射向，毒雾、符书保留地面落点；石弹、毒灯弹与鱼叉现在也按实际高度瞄准。第一人称现已显示双手、前臂和各角色袖口，武器有独立取景与出手、回收动作，并细化枪械、书页、灯芯与法杖结构；采用程序化持握，尚非专门制作的完整手臂动画资产。地形基底仍以原有平面为主；跳跃已按实体高度判断，可越过矮石、倒木和低栏，也能落在这些障碍的顶部、走下边缘后下落。高树、高墙和屋顶仍会阻挡，暂不含攀爬和建筑室内。

闪避随视角呈现：第一人称翻滚收械并降低视点，潜潮时下潜并收起长叉，侧跃轻微侧倾；第三人称翻滚沿实际移动方向，瞬移以正常身形隐去和现身，镜头立即跟到落点。潮汐长叉从后手向前伸出，分别表现前刺、横扫与回收；普通命中特效跟随实体表面，近距离会收敛尺寸。长叉的刺出进一步对齐实际命中点，枪弩、暗影、长叉与双提灯采用各自的短促接触表现，真实命中时准星闪一下。原有位移、冷却与免伤时间保持。

第一人称战斗默认隐藏并尝试锁定鼠标，直接移动转向，不必按住右键；战斗期间避免误点顶部与 HUD。按 Esc 暂停后，可切换「战斗鼠标：显示 / 隐藏」，偏好自动保存；成长、奖励等弹窗恢复正常鼠标选择。显示鼠标时可按右键拖动转向。浏览器拒绝锁定时仍隐藏光标并允许画面内转向，但受窗口边缘限制；从暂停菜单继续时会重试。

电脑自动攻击模式会寻找视野内附近目标并出手；手机默认自动瞄准，需按住右侧攻击键才攻击，松手停止，也可选择手动瞄准。手机暂停 →「设置」可调整移动、攻击、闪避、跳跃与下蹲键大小（75%–135%），选择自动保存。手机战斗顶部只保留暂停入口；视角、横屏和声音选项也收在暂停 →「设置」。新物种与事件在上沿短暂提示，完整怪物介绍在暂停 →「图鉴与介绍」，发现记录跨局保留。手机横屏优先，也支持竖屏；电脑和手机均可在探索地图中查看已发现地点、设置路标。

跳跃相对起跳面最高约 1.09 米、回到同高度时约 0.68 秒，能越过足够低的障碍、震地与低位掠击；落在矮物顶部后仍能移动、下蹲与再次起跳，走下或支撑物消失时自然下落；下蹲身高约为站立的 55%、移动速度 48%，能避开高位扫击。两者都不额外提供无敌；毒雾和高柱攻击仍危险，深水中继续使用原游泳操作。第一与第三人称都可上下瞄准，镜头接近垂直俯仰也能发射，发射位置跟随蹲跳。

各地图新增一种空中巡游怪：暮翼蝠、霜羽蛾、烬翼蝠、沙金翼甲、潮风鳐。24 秒后有机会占用普通增援名额，场上最多三只；它们会盘旋、收翼蓄力、锁定方向俯冲，随后低飞恢复，留下近战与贴地毒雾的反击机会。图鉴列出外形与躲避方法。

## 离线游玩

安卓与 Windows 10/11 可直接下载[本次发布的完整包](https://github.com/dont-cry-522/last-survivo-3d-reborn/releases/tag/v230)。安卓安装 APK 后打开「异境回响 REBORN」；电脑版完整解压 ZIP 后双击「启动异境回响.exe」，使用电脑已有的 Edge 或 Chrome 进入独立全屏离线窗口，没有地址栏，不需要另外安装 Python 或 Node.js。`Esc` 暂停，`F11` 切换全屏/窗口，`Alt+Tab` 切换应用，`Alt+F4` 退出；关闭游戏窗口会同时结束本地服务，不关闭其他浏览器窗口。

电脑版同一文件夹中的 `START_ONLINE_ROOM.cmd` 用于联网开房，窗口保持打开；手机或电脑朋友从完整邀请链接进入浏览器。安卓 APK 保持独立离线单机，联机仍从浏览器邀请进入，两者存档不会自动互通。临时公网入口依赖外部转发服务，不能保证所有网络下可达或不断线。

启动器使用所选浏览器的正常用户资料，不使用隐私模式；更新时继续选之前使用的同一浏览器。已有同包名安卓版本可覆盖安装，不要先卸载。安装版、网页和电脑本地版的存档分别保存在各自来源，不能自动互通。

1. 首次联网打开游戏，展开右上角「下载 / 离线」，点击「保存到本浏览器」。这是浏览器缓存，不会把文件保存到你指定的磁盘文件夹。
2. 等待资源准备好后，可添加到桌面或收藏游戏地址；之后使用同一浏览器，即可断网重新打开。
3. 已下载离线版会在联网打开时自动检查更新，下载完成后在准备页主动启用，不打断正在进行的对局。资源缺失或下载中断可重试修复。

首页标题旁会显示版本号。若旧收藏一直打开旧版，请使用上方「开始游戏」新入口，无需清除网站数据。

游戏记录和离线资源保存在当前浏览器；清除网站数据会一并清除。安装入口取决于浏览器支持，未安装时仍可从已保存资源的浏览器离线打开。运行需要支持 WebGL 的现代浏览器。

也可以点击「保存完整离线包 ZIP」把游戏存到磁盘。支持保存文件选择器的电脑浏览器会让你选择文件夹和文件名；其他浏览器使用普通下载，保存位置由浏览器设置决定。下载可取消，只有资源完整并校验通过才会完成 ZIP。包内不包含浏览器存档。

把 ZIP **完整解压**到所选文件夹，Windows 双击 `START_OFFLINE.cmd`；电脑需预先安装 Python 3 或 Node.js，任选其一。macOS / Linux 可在解压目录运行 `python3 start-offline.py` 或 `node start-offline.mjs`。保持启动窗口打开，在 [本机游戏](http://127.0.0.1:8897/play.html) 游玩，准备好运行时后无需外网。不能直接双击 HTML。详细步骤见包内 `OFFLINE_README.txt`。

手机可下载 ZIP 备份，但多数手机浏览器不能直接运行解压后的网页模块；手机离线游玩推荐前面的浏览器缓存方式。在线网址与本机网址的存档互不共享；更新本地包时继续使用同一浏览器及固定的本机地址，不清除网站数据。

人物与光照改动见 [视觉实装记录](docs/visual-upgrade-v216.md)，首次加载与装备切换见 [v224 验证记录](docs/performance-v224.md)，连续游玩与首次技能准备见 [v225 验证记录](docs/performance-v225.md)；本次海港远岸与正式游玩性能复核见 [v227 验证记录](docs/coast-release-v227.md)。

## 本地运行与开发

两张新图的路线、地形、事件和复用资源见[新地图说明](docs/设计参考/07-新地图与探索.md)。所有运行时资源保存在仓库中；单机运行不依赖好友房间服务。

在本目录启动静态服务器：

```sh
python -m http.server 8897
```

打开 [本地游戏](http://localhost:8897/)。不能直接双击 HTML 文件运行模块。Three.js 已包含在仓库中，运行时无需第三方 CDN；房间服务和完整自动测试使用 Node.js，并先通过 `npm ci` 安装锁定的本地服务依赖。

修改游戏资源后，重建离线清单并检查：

```sh
npm run offline:build
npm run offline:check
npm test
```

`tests/browser-*.cjs` 是可选的 Playwright 浏览器检查，可通过 `PLAYWRIGHT_MODULE`、`BROWSER_EXECUTABLE`、`TEST_URL` 指定已有环境；[声音试听页](tests/audio-listening.html)可通过同一静态服务器打开。自动检查和手机尺寸模拟不等同于长局平衡、主观听感或安卓真机与低端 GPU 验证。
