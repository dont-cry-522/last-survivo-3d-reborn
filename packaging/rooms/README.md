# 异境回响 REBORN · 好友房间快速开始

房主用 Windows 10/11 的 64 位电脑开房，朋友用手机或电脑浏览器加入。最多 4 人，至少 2 人：玩家互相对战，地图上也有怪物。

## v228 合包的两个入口

`Realm-Echoes-REBORN-v228-Windows.zip` 全部解压后：

- 自己断网玩：双击 **启动异境回响.exe**，沿用原浏览器资料及 `http://127.0.0.1:8897`，以独立全屏窗口运行。F11 切换全屏，Alt+F4 退出。
- 开房邀请朋友：双击 **START_ONLINE_ROOM.cmd**，按下方步骤通过浏览器开房；联机服务器使用 8898。

两个入口共用一个 `game` 资源目录，存档仍按原有网址隔离，不会自动同步。手机 APK 是离线单机版；手机参加好友房间需用浏览器打开完整邀请。

## 异地联机：朋友直接用浏览器打开邀请

**不要求同一 Wi-Fi，不要求朋友安装 VPN 或 Tailscale，也不要求朋友注册账号。** 房主电脑通过包内的 Cloudflare Quick Tunnel 建立临时 HTTPS 入口，朋友用普通浏览器打开邀请，可使用自己的 Wi-Fi 或手机流量。

1. 房主把 ZIP **完整解压**到自己选择的文件夹，不要在压缩包内直接运行。
2. 双击 **START_ONLINE_ROOM.cmd**，等待“HTTPS 入口已验证”。启动器会先启动本机游戏服务，再建立隧道，并检查网页和 WSS 对战连接；没有验证成功不会发出邀请。
3. 把窗口显示的**房主本机专用网址**复制到电脑 Edge 或 Chrome。这个 `127.0.0.1` 网址只供房主使用，让游戏资源与对战同步直接连接本机。载入游戏后点 **好友房间 → 创建私人房间**。
4. 房主在游戏房间里点 **复制邀请**，自动生成本次 **HTTPS 公网链接**，把它发给朋友；不要发窗口中的本机网址。朋友用手机或电脑浏览器打开，选择名字、人物、武器，再点 **加入房间**。
5. 每人点 **准备**，全部准备后房主点 **开始对战**。所有设备载入完成后一起进入。

房主的服务窗口和游戏页都必须保持打开。关闭窗口或按 Ctrl+C 会关闭本次隧道和游戏服务。**重启后网址会变化，需要重新复制邀请；不要只发送房间码。** 网址中的邀请钥匙只分享给一起玩的朋友。

### 免费测试入口的实际边界

此方式不租云服务器、不买域名，不需要 Cloudflare 账号，也不修改路由器端口转发。它使用官方 Quick Tunnel，属于临时测试服务，**没有在线时间或延迟保证**，每条隧道最多 200 个同时处理中的请求，超限会返回 429。不是固定地址的正式运营服务器。[官方说明](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/)

首次载入仍会使用房主的上传带宽和朋友的网络流量。某些网络可能无法访问临时域名或连接不稳定；不能保证任何网络都能连接、零等待或永不卡顿。本包不自动切换为局域网，也不安装系统服务或修改用户已有的 Cloudflare 配置。

主机隧道默认使用 HTTP/2（TCP）。真机测试曾遇到 QUIC/UDP 超时，中断模型下载与对战连接，因此改用此传输方式；是否在各自网络下稳定，仍需实际游玩验证。

### 启动不成功时

- **缺少 cloudflared**：重新完整解压带 `runtime` 文件夹的异地联机包，勿单独复制 CMD。
- **端口被占用**：先关闭另一次正在运行的开房窗口，再启动一次；程序不会把占用该端口的其他软件发布出去。
- **建立入口超时 / 隧道退出**：检查电脑互联网连接、系统是否阻止包内 `cloudflared.exe`，再重试。错误窗口会显示可用的隧道诊断，不需要登录 Tailscale。
- **朋友打不开**：检查房主窗口是否仍在运行，并使用本次完整 HTTPS 邀请。请不要改成 127.0.0.1、局域网地址或原来 GitHub 网页。

当前启动器会实际检查 HTTPS 和经过邀请验证的 WSS 连接。**不同真实网络的四台设备对战仍需单独实测**；本机自动化测试不代表蜂窝网络或任何外网环境已验证。

## 同一 Wi-Fi：不使用 Tailscale 的可选方式

1. 把 ZIP **完整解压**到自己选择的文件夹，不要在压缩包里直接运行。
2. 双击解压目录的 **START_PRIVATE_ROOM.cmd**。
3. 在窗口中选择电脑当前的**局域网 IP**，通常是 `192.168…` 或 `10…`。不要选“仅这台电脑测试”，否则手机进不来。
4. 把窗口显示的**完整私人网址**复制到电脑 Edge 或 Chrome。游戏载入后点 **好友房间 → 创建私人房间**。
5. 在房间里点 **复制邀请**，把完整链接发给朋友。朋友用手机或电脑浏览器打开，选择名字、人物和武器，再点 **加入房间**。不要只发送房间码。
6. 大家分别点 **准备**，全部准备后由房主点 **开始对战**。所有设备载入完成后一起进入。

请保持服务窗口和房主游戏页打开。关闭服务或房主退出会结束房间；没有自动更换房主。若 Windows 询问网络访问，只允许你信任的私人网络，不要关闭防火墙。

## Tailscale 备用方式（自愿选择）

已有私人组网、希望直接互通的朋友可使用 **START_TAILSCALE_ROOM.cmd**。这是备用方式，**不是上方 HTTPS 主入口的前提**。

所有设备从 [官网](https://tailscale.com/download) 安装 Tailscale；房主用自己的个人账号登录，并在 [管理页面](https://login.tailscale.com/admin/users) 的 Users → Invite external users 邀请朋友。朋友各用自己的账号接受邀请，在应用里连接房主的同一个私人网络，不共享密码。手机 VPN 提示由本人同意；需要审批时由网络管理员批准。启动器只在已登录、在线且本机获得实际 Tailscale IPv4 后开房，不回退 LAN。

截至 2026-10-20，[Personal 官方方案](https://tailscale.com/pricing) 为 $0、最多 6 位用户，适用于非商用游戏；政策以后可能变化。Tailscale 组网邀请用于首次网络设置，游戏房间邀请用于进入本局。软件安装、账号和设备授权由各自主人完成。

## 对战中

- 当前源码构建为 8 位英雄、19 种武器、7 张独立地图和原五境合流，保留手机触控与第一/第三人称。旧 v227 包不含岚歌及两张新图。
- 倒地 8 秒后满血复活，保留本局成长，复活后保护 2 秒。
- 普通地图击败 3 位首领后结算；五境合流地图是 5 位区域首领。
- 选择升级或奖励时全房暂停；个人菜单不暂停战斗。房主切到后台时全房暂停。
- 结算后房主可回到房间再开一局。开局后暂不能中途加入或断线续接。

## 构建与校验

先冻结游戏并完成离线清单与测试，再执行：

```powershell
python packaging/windows/build.py --output ../../outputs/reborn-release-v228/staging
python packaging/android/build.py --toolchain ../android-toolchain --output ../../outputs/reborn-release-v228
python packaging/rooms/build.py --output ../../outputs/reborn-release-v228 --node "C:/Program Files/nodejs/node.exe" --cloudflared ../../outputs/public-room-setup/cloudflared.exe --offline-package ../../outputs/reborn-release-v228/staging/异境回响-REBORN-v228-电脑离线包.zip
python packaging/verify-deliverables.py --output ../../outputs/reborn-release-v228
```

输出交付清单仅列 Android APK 与 Windows 合包；`staging` 内的离线 ZIP 是中间产物。合并拒绝不同版本、失效清单、未通过原生服务校验、重复 ZIP 项及任何内容不一致的同名文件。最终校验包括本地资源、运行时与许可、单机地址及两个启动入口；不等于实际手机安装、游戏帧率或公网延迟验证。
